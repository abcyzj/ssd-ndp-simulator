# M2.3 功能算子与成本模型

2026-10-28（Asia/Shanghai）。依据 PRD FR-03/07、实施规划§4/7、任务清单默认值。前置 M2.2 已完成其运行时范围，保留的依赖证据见 [M2.2](m2.2-async-visibility.md)。本任务未改变范围或资源归属，未开始 M3.1。

## 功能与工作量

`src/operators/operators.{h,cc}` 提供纯函数平方 L2 和候选控制算子。输入采用显式 little-endian IEEE binary32；先转 binary64 再相减、平方，按维度顺序 binary64 累加。CMake 对算子明确设置 `-fno-fast-math -ffp-contract=off`，Release 下亦保留数值顺序。空 query、尺寸不匹配、非有限数、重复评分 ID、损坏的打包结果均明确拒绝；非空 query 的空评分批次合法。所有有限 FP32 差值的平方及可容纳向量的和均在 FP64 范围内。

结果使用无隐式 padding 的 little-endian uint32 ID + binary64 distance，每项 12 B。主机已有 ID 仍保留该统一逻辑表示；它是本地结果大小，不表示产生 12 B PCIe 流量。后续传输适配器必须按实际 wire schema 独立计费。

批次含 b 个 d 维向量时，Work 描述：elements=bd、flops=3bd（减、乘、加各一次）、read_bytes=4d+4bd、write_bytes=output_bytes=12b。读取量表示 query 一次与向量数值的逻辑有效字节，ID 元数据不算数值输入量；不表示实际 CPU load 指令、缓存 miss、sector 或 PCIe 字节。工作量来自实际批次及结果，不从墙钟推断。

`candidates(packed, limit)` 接受现有候选和新增分数，逐条检查，按 ID 去重并保留较小距离；确定性插入排序后按 `(distance, uint32 ID)` 截取前 limit 项。每个输入计一次 candidate_check，每次 ID 相等判断或距离/ID 比较器调用计一次 comparison（比较器内部不另拆微操作）。输出大小随去重及截断变化。排序前保留全部唯一项，采用易核对的 O(n²) 实现；visited、expanded、候选合并的阶段划分由未来算法调用者负责，未实现图搜索。没有提前退出或内部阶段依赖，整项工作作为一个服务任务。

## 主机服务

`src/model/host_cpu.{h,cc}` 是受信 invoke 适配器，复用 M2.2 Runtime、既有 EventBridge 和 SST now。输入必须是已按模拟路径到达 HostMemory 的运行时句柄；依赖满足后进入共享 FIFO，主机距离与控制任务竞争同一组 slots。每 slot 非流水，服务完成释放 slot，独立任务可继续执行。实际功能结果在输入及 slot 就绪后生成，暂存在运行时私有结果槽，服务完成后的 Publish 才可读。

| 类型 | 工作单位 | 服务公式 |
| --- | --- | --- |
| Distance | Work.flops | distance.setup_ns + ceil(flops / distance.units_per_ns) |
| Control | checks × check_units + comparisons × comparison_units | control.setup_ns + ceil(units / control.units_per_ns) |

配置均使用 uint64：时间为 ns、rate 为正整数 units/ns、slots 为正整数，权重可为零；空工作量仍收 setup。整数除余实现向上取整，拒绝计算和时间加法溢出。配置必须保留非空 source，默认 `configured_unvalidated`。当前只提供整数 rate；分数速率及流水启动间隔不支持。

HostCpu 的 Service 记录保存 task、提交/start/end、工作量与服务时间。提交至 start 含依赖等待和 FIFO 等待，尚未单独分解两者。综合距离 rate 包含数据加载假设，不再叠加主机 DRAM/缓存服务。主机功能墙钟、LE 编解码、研究观测不另收费。输出 Work 和实际 Bytes 长度不符拒绝；功能异常、成本溢出释放 slot，排队失败项跳过，在服务期间外部失败的任务仍占用至原定完成时刻，届时释放但不发布。

HostCpu、Runtime、EventBridge 必须活到所有回调排空；不承诺销毁时取消或 MQSim 在途错误恢复。受信 evaluator 负责准确描述工作量，不能把该低层接口作为算法任意读取 ContentStore 的途径。真实 read 适配、设备计算、PCIe 消息、缓冲 credit、完整输出配置和图搜索仍由后续任务实现。

## 验收

复现：`python3 tools/verify_m2_3.py`。根 CMake 默认准备锁定 SST，共享缓存命中可复用；无 SST/MQSim 源码改动。实际命令、退出码、日志、源码/输入及输出哈希在 [证据索引](evidence/m2.3/README.md)。

手算向量 query=[1,2,3]、vectors=[[4,6,3],[-1,2,4],[1,2,3]] 得平方距离 25/5/0，9 elements、27 FLOPs、48 B 输入、36 B 输出。额外检查 FP64 减法精度、固定累加顺序、最大有限 FP32、同分 ID 顺序、去重和错误输入。

公式表使用人工参数：distance setup=3 ns、rate=4 FLOPs/ns，27 FLOPs 得 10 ns；control setup=2 ns、rate=3 units/ns，checks=4、comparisons=8、权重 2/3 得 13 ns。零工作、整除、余数、加倍速率和溢出均有断言。混合实际批次一 slot 完成于 10/15/25 ns，两 slots 完成于 10/5/15 ns。

快慢实现对相同输入执行等价功能，慢实现重复 20000 次，返回相同结果和单次工作量；验证墙钟增大而模拟服务逐行相同。独立进程重跑只排除墙钟字段，其余输出完全一致。真实 SST 用受控输入到达 5 ns、距离服务至 11 ns、控制至 13 ns，6 ns 提前读取拒绝，最终结果全部释放。

此处仅覆盖 AC-02 的数值部分、AC-10/11 的隔离主机模型部分；完整闭环访问分支、端到端复现和参数回归仍待后续任务。全部参数未校准，不代表绝对性能、共享 DRAM 竞争或盘控更快。
