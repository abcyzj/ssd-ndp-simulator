## 实现与使用边界

[LocalReads](../../../src/backend/local_read.h) 是平台正式本地存储适配器。调用者提供 Layout、带对象/version/范围的 selections、非零 query/task 和完成回调；每次 submit 分配 operation ID，完整计划先校验后才提交。一个 operation 可以合并多个对象、拆成多个后端请求；ReadAssociation 绑定 extent 与 local token，所有请求完成后恰好通知一次。实例独占 host 的本地完成队列，并须存活到自己的事件桥回调排空。

MQSim 继续直接编译 `third_party/MQSim`，保留 E2 的独立 DEVICE_LOCAL route、namespace 范围检查及原生分页。新增只读预校验入口和稳定事务 ID：每个本地事务在提交时记录 ID、LPA、sector bitmap、字节数；现有 cache 的 memory-transaction-serviced 信号记录实际完成时间，不引入第二个 PHY 观察者或存储计费者。普通/后台事务的扩展 ID 为 0，不强行关联到当前查询。本任务不扩展共享命令参与集合或 M4.1 完整观测。

本地请求仍经过 cache→FTL/CMT→TSU→PHY/NAND。最后一个事务移出请求列表且缓存服务计数为零，才预约同刻清理。PHY 信号 fanout 返回前请求保持存活；事务由 PHY 释放，同刻清理删除请求和进度表，再输出不含指针的值记录。记录含 native request ID、local token、stream、LBA、sectors、bytes、提交/完成时间及全部事务记录。部分完成不会发布请求完成值。

平台按完整请求和事务元数据校验记录，拒绝重复/未知 ID、错误地址/字节、缺失事务、未完成标记和非法时间；所有 extent 成功后，在 EventBridge 的 ResourceCompleteRelease 阶段删除在途关联对象，再通知存储消费者。只保留 token→query/task 的值类型 tombstone 用于重复完成诊断，不保留后端指针、请求对象或事务快照。tombstone 随适配器析构释放，有限实验内按请求数增长。

回调是 **Storage ServiceDone**，不是 DeviceBuffer Visible。适配器没有 publish 或功能数据读取权限，不产生普通 SQ/CQ/SQE、完整向量 DMA 或 PCIe 费用。调用者应在 submit 前预留 credit；接到完成后进行 staging，再授予 DeviceBuffer 可见性。这些资源与可见性阶段属于 M3.3，本任务不以零延迟 staging 代替。测试明确检查存储回调发生时 handle 仍为 NotReady，并核对调用者已 release 后由 in-flight pin 保持生命期，最终全部回收。

## 失败与所有权

- 参数、布局、namespace 或未支持缓存在整个计划提交前拒绝，不发送部分 I/O。分配/拆分在交给 cache 前异常时，已建立的事务由提交入口回收。
- 注入后的不可恢复后端错误、未知/重复/损坏的完成值抛出 BackendFailure；已知关联保留 query/task/request/当前时间，未知 token 不伪造 query。研究诊断可列出所有在途 operation/query/task、local/native request ID 和事务 ID，真实 SST 的致命错误出口附带此信息。适配器进入失败状态，不再接纳提交或发出已排队的成功回调。实验必须非零退出。
- 不删除已经交给 cache/FTL/PHY 的事务来伪装取消成功，不承诺在途取消、失败回滚或同进程恢复。终止时由进程与设备生命周期释放容器；既有 MQSim 完整在途泄漏审计限制继续保留。
- 正常完成时 MQSim 请求 owner/进度表、平台 operation/request 关联和内容 in-flight pin 全部归零。回调只携带值记录，消费者不持有失效的后端指针。

## 复现与验收

```sh
python3 tools/archive/v0.1/verify_m3_2a.py
```

脚本通过根 CMake 默认共享 SST 缓存配置与构建，执行完整 CTest、真实 SST 重复运行、受控正序/倒序 PHY、逆序请求交付、错误完成注入、ASan，以及从 deps.lock.json 原生 commit **独立 git archive 导出**的普通读 oracle。不是从当前修改工作区构建原生对照。输入是 native-small、SIMPLE/TURNED_OFF、保留 CMT；测量前确定性预装载 0:512 sectors 并排空，测量时钟不重置。

固定本地夹具：两个父操作 query/task=1/11、2/12；各读取 LBA7 的 3 sectors 和 LBA32 的 1 sector。真实逻辑内容 1040+40=1080 B/操作，sector 覆盖 2048 B/操作；LBA7 拆成 LPA0 的 512 B、bitmap128 和 LPA1 的 1024 B、bitmap3，LBA32 为 LPA4 的 512 B、bitmap1。共 4 请求/6 事务，事务 ID 唯一。普通读 LBA48 的 1 sector 在本地工作全部完成后发起，实际数据到达与 CQ 消费继续由原普通路径确认。

[本机证据索引](../../evidence/m3.2a/README.md) 和 manifest 保存所有命令、退出码、输入哈希、依赖完整 commit、相对原生基线及 HEAD 的 diff 哈希、实际 MQSim 源码逐文件哈希。原始日志位于同目录；`docs/evidence` 沿用仓库约定不纳入 Git，新检出用脚本重建。

## 限制

仅单设备/单进程/单 rank/thread、已有 namespace、只读 sector 路径、SIMPLE/TURNED_OFF，保留 CMT；其他缓存配置明确 Unsupported。无 query/command/result PCIe 消息、credit/staging/盘控计算、两放置端到端搜索或共享 DRAM 竞争。受控逆序交付会人为延迟通知，只作为关联测试，不用于性能结论。所有人工参数仍未校准，不据此声称盘控更快或绝对性能准确。ASan 用于本任务访问安全回归，未宣称完整上游泄漏/UBSan 审计通过。
