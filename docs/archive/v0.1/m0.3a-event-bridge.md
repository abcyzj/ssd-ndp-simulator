## 实现

- 直接修改 `third_party/MQSim/src/sim/Engine.{h,cpp}`，新增 `Peek_next_time`、`Synchronize_now`、`Dispatch_current_time` 和队列变更观察回调。沿用 M1.1 的 `Initialize_simulation`，初始化不消费事件。使用原有整数 ns、EventTree 同刻 FIFO 和 Ignore 标志；不修改 SST Core。
- peek 清理最早位置的 Ignore 事件信封，参数仍由原有所有者管理；返回空 optional 表示没有有效事件。分派先弹出当前事件，再执行回调，并持续吸收同刻新增事件；不执行未来事件。同步时若存在过去的有效事件，或出现时间倒退，立即报错。默认同刻分派上限为 100000 个有效事件，触发后保留未分派事件并报错；递归分派也拒绝。
- 队列插入/Ignore 通知只作预约提示，观察回调可 peek，不应再次插入、Ignore 或分派；后端分派阶段合并通知，稳定后重新预约。Reset 清除观察回调。Ignore 后不能继续使用可能已被 peek 回收的事件指针。
- 新增独立 `ndpsim.BridgePoC` SST 组件，复用 `LifecycleBackend` 构造真实单 SSD，再注册确定性 MQSim `Sim_Object` 回调夹具；没有 Host、请求 flow 或算法。SST timebase 与 SelfLink 均为 1 ns；下一后端时间用 SelfLink 精确预约，generation 使旧预约失效。过期唤醒不修改 MQSim 时钟。该组件只接受单 rank/线程、一个固定设备、无参数的测试场景。
- 已有后端事件先于同刻外部提交执行；20 ns 提交产生的同刻事件在下一后端阶段处理，无额外 1 ns。这里只实现 E1 所需阶段，不实现通用 `(time, delta, phase, sequence)` 调度器。`LifecycleBackend.finish` 允许非零时刻结束，但拒绝仍有有效后端事件的成功结束；原 `System` 的 1 ns/0 ns 生命周期探针保持原输出。
- 原生 `Start_simulation` 的循环未重写；新增独立进程探针验证其同刻 FIFO/Ignore 行为。正式共用循环、真实读对照和完整停滞诊断留给 M1.2/M1.3。

## 夹具与判定

真实设备初始化后夹具仅预约 10 ns 的 type 1、2 和 30 ns 的 type 8；另有被 Ignore 的 15 ns 事件。10 ns 回调新增 type 3，type 3 再新增 type 4，验证同刻追加不会丢失或越过已有事件。

20 ns SST 外部事件到达时断言 MQSim 已同步为 20、下一事件仍为 30。先插入 25 ns/type 7，使原 30 ns 预约过期；再插入 22 ns 事件并 Ignore，验证更早预约及取消造成的过期唤醒；同刻插入 type 5，由它再生成 type 6。

| 顺序 | SST ns | MQSim ns | type |
| --- | --- | --- | --- |
| 1–4 | 10 | 10 | 1、2、3、4 |
| 注入 | 20 | 20 | SST 外部事件；下一后端事件仍是 30 |
| 5–6 | 20 | 20 | 5、6 |
| 7 | 25 | 25 | 7 |
| 8 | 30 | 30 | 8 |

实际过期唤醒为 22 ns/generation 4、25 ns/generation 3、30 ns/generation 2；其到达时 MQSim 分别仍为 20、20、25 ns，均无分派。最终 `events=8`、`stale=3`、队列为空，SST 在 30 ns 结束。独立两次运行的 E1 全部日志行一致。

后端探针还覆盖：初始化前同步、重复初始化、跨过未处理事件、倒退、过去插入、未来事件不提前执行、同刻链中的 Ignore、空队列同步、队列变更通知、同刻无限追加上限及上限后恢复。所有断言使用异常检查，不依赖会被 Release 禁用的 C assert。

## 限制

这是运行 E1 的 PoC，未发起真实 I/O，未复跑或重建未修改原生小读 oracle，也未改变其身份；没有完成 AC-08 的逐请求原生时序对照。SSD 参数仍为 configured_unvalidated，不代表绝对性能校准。无算法运行时、本地读取 route、通用资源阶段调度器、多 SSD 或同进程多实验支持。

验收运行时未改变依赖锁和 gitlink，MQSim 引擎改动以工作区 diff 与实际源码哈希记录。验收后按用户批准的 message 将引擎改动提交为 `a5ed06a`（`feat(sim): add externally driven event stepping APIs`），主仓随本次提交更新 gitlink；未推送或初始化 Git。SST Core 保持锁定 commit 且无工作区修改。上游 Reset 的队列释放及长期分配未做完整审计，支持场景在结束前排空队列；不承诺在途 I/O 安全清理或泄漏检查通过。M1.1 已记录的 UBSan 随机数溢出限制仍然存在，本轮没有用 UBSan 或修改该算法。详细因果链、全局任务停滞诊断及真实 I/O 生命周期验收仍属后续任务。
