# M1.2 正式事件桥

> V0.1 历史归档（2026-10-30 收尾）。阶段状态、命令与结论仅对应当时范围；不作为当前需求或执行指令。现行入口：[文档索引](../../README.md)、[版本交接](../../releases/v0.1.md)。正文中的输入哈希是历史身份，归档改写链接后不代表本文件当前哈希。

2026-10-27。依赖 M1.1、M0.4 已完成；遵循 PRD FR-05、实施规划§4与冻结契约§3，不改变模型取整或任务范围。

`src/backend/event_bridge.h` 提供可复用 EventBridge，注入 SST now 和预约回调；MQSim 保持直接源码编译。`src/sst/event_bridge.cc` 展示真实 SST SelfLink 接入和受控验证；旧 BridgePoC 保留为历史 E1 回归入口。

桥按 `(ns, delta, phase, sequence)` 调度，phase 为 Backend、ResourceCompleteRelease、Publish、ContinueSubmit。同阶段 FIFO；后向阶段进入下一 delta；Backend 内保持 MQSim 原生 FIFO、同刻新增与 Ignore 语义。SelfLink 仅预约，无额外模拟收费。每次处理同步至 SST now，禁止跨过尚未处理的有效后端事件。queue changed 自动重新检查预约，generation 替换旧预约；过期唤醒不推进 MQSim。析构撤销观察回调，桥不可复制；所有者必须先销毁桥再 Reset 后端。

同刻平台事件与后端事件分别默认上限 100000，跨 delta 累计；提供可调低的测试界限。Stalled 报告 SST/MQ 时间、generation、delta/phase、计数及最近八个平台 cause。`require_progress(unfinished, detail)` 检查无有效预约而仍有在途工作；调用方需提供实际 task/request/credit 等上下文。后端已停止而仍有当前片事件也报错。V0.1 失败退出，不提供回滚恢复。MQSim `Engine.cpp` 仅增强同刻派发上限错误，带待处理事件 target/type/time；不改变事件或时间语义，直接修改子模块源码，其未提交 diff 和实际源码哈希记录于 manifest。桥不内联调用 continuation，调用者通过对应 phase 入队。

复现：

```sh
python3 tools/archive/v0.1/verify_m1_2.py
```

该入口执行根 CMake 配置/构建、完整 CTest、两次 SST 受控请求、正式桥 E1 和诊断探针，并从 deps.lock.json 的原生 MQSim commit 独立 `git archive` 导出原生 Engine/EventTree 构建 oracle；不使用开发 MQSim 库充当原生 oracle。保留命令、退出码、输入/日志哈希与 MQSim 相对基线 diff/实际源码身份。见 [证据](../../evidence/m1.2/README.md)。

受控请求固定 ID 1～4：前两个 10 ns 提交，后两个 20 ns 提交，服务 7 ns；同刻提交按 FIFO。原生输出和 SST 输出都必须逐请求为 `(1,17),(2,17),(3,27),(4,27)`。这是整数 ns 调度请求，不是 NVMe/FTL/NAND I/O 验收。原生源码未修改，仅增加独立测试驱动；没有改变任何原生传输量化规则。

限制：单设备、单进程、单 rank/thread；调用方应把平台事件汇入本桥，不能依赖跨组件隐式同刻顺序。未来运行时仍需正确维护 unfinished 和 cause，当前没有 M2 task/credit/message 生命周期。AC-08 只完成 M1.2 所负责的时间桥部分，M1.3 普通 I/O、确定性初态及后续本地/共享传输仍未验收。参数未校准；未做泄漏审计。没有开始 M1.3。
