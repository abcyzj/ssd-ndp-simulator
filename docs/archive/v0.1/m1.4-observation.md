# M1.4 基础观测

> V0.1 历史归档（2026-10-30 收尾）。阶段状态、命令与结论仅对应当时范围；不作为当前需求或执行指令。现行入口：[文档索引](../../README.md)、[版本交接](../../releases/v0.1.md)。正文中的输入哈希是历史身份，归档改写链接后不代表本文件当前哈希。

2026-10-27：完成本任务限定的 AC-09 基础观测。依赖 M1.3 已完成；需求为 FR-08、实施规划 §8/AC-09。未启动 M2 或 M4。

研究者接口由 `src/backend/observation.h` 实现，普通 SST I/O 配置通过 `NDPSIM_OBSERVE=1` 开启，默认关闭。输出 stdout 的 `OBS ` JSON 行和 `STAT ` JSON 行，可按前缀提取；不是算法运行时接口。MQSim 内直接增加被动 hook，不修改 SST，不注册额外事件，不收费，不改变服务时间。

| 能力 | 状态及定义 |
| --- | --- |
| device/request 提交与 CQ 完成 | Extended；稳定 external-flow token、绝对 ns、LBA、sector bytes；CQ 已验证数据到达 |
| channel bus | Extended；实际结束的 command、command+data-in、data-out 传输区间的并集；不把 array 算成 bus |
| die array | Extended；实际 command execution 开始至结束，含原生 R/B 延迟；按 channel/chip/die 分组，不用 chip busy 替代 |
| die data-out | Extended；实际 data-out 起止，可与其他 die array 重叠 |
| die wait_data_out | Extended；array 结束至首次 data-out 开始，多 plane 后续传输为上次 data-out 结束至下次开始；零等待明确输出 |
| request 排队等待细分、请求到内部事务/共享命令参与集合 | Unsupported；当前 chip hook 不持有这些身份，事件用 null 和原因明确表示，不填零或伪造关联 |
| QueryId/TaskId、delta/phase、causal_parent | 尚未接入算法运行时；当前仅存储夹具，无算法 ID；sequence 是输出顺序，不是 SST 调度序号 |
| plane/latch 占用、暂停恢复、共享 DRAM/能耗 | Unsupported；只验 native-small/SIMPLE/TURNED_OFF 只读测量，无暂停/恢复或任意 GC 矩阵保证 |

所有区间来自实际结束边界，不提前把预计完成时间暴露为实际观测。区间事件离线汇总输出，time_ns 是区间结束时间，输出并不保证按时间排序。测量窗口为确定性预装载排空后的首次读提交到最后一次 CQ；起止裁剪，半开区间。`union_ns` 的分母为单个实体的 window_end_ns-window_start_ns；未输出实体表示没有活动样本，不能解释成 Unsupported 或输出不存在粒度的零值。当前不输出多实体平均利用率。请求 bytes 是 sector 口径，不代表 ONFI wire bytes。

验证入口：`python tools/archive/v0.1/verify_m1_4.py`。独立 Python 核对器用端点扫描重算并集，生产 C++ 用排序区间合并。受控探针覆盖跨窗口裁剪、重叠总线、不同 die 与非零等待；真实 SST 使用 QD1、32 并发跨页、128 B 小 CMT 三组，各关闭/开启/再次开启，逐请求核对 LBA、大小、方向、完成时刻及初态。事件开启重复输出一致。另重跑 `python tools/archive/v0.1/verify_m1_3.py`，三组逐请求仍匹配独立锁定原生 oracle，退出码 0。详见 [证据](../../evidence/m1.4/README.md)。

限制：事件缓存在内存中直到报告，只适用于基础验证规模；M4.1 仍负责完整输出、日志/统计开关解耦、算法关联及流式大规模日志。现阶段不宣称完整 AC-09、绝对性能校准或完整后台 source 归因已完成。验收时 MQSim 修改尚未提交，manifest 记录当时相对锁定原生基线的 diff 哈希和实际源码文件哈希。随后按用户指令将 MQSim 修改提交为 `a1213c22c5ca7bd806cf80a2a7ad27bd743829f6`（以子模块 gitlink 为准）；主仓同步更新 gitlink，原生 oracle 的锁定 commit 保持不变。未推送任何仓库。
