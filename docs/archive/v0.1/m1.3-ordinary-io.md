# M1.3 普通 I/O 与确定性初态

> V0.1 历史归档（2026-10-30 收尾）。阶段状态、命令与结论仅对应当时范围；不作为当前需求或执行指令。现行入口：[文档索引](../../README.md)、[版本交接](../../releases/v0.1.md)。正文中的输入哈希是历史身份，归档改写链接后不代表本文件当前哈希。

本任务依赖 M1.2 正式事件桥；已核对任务表、PRD FR-04/05/10、AC-08 和实施规划 E5。范围保持单 SSD、单进程、只读测量负载；不启动 M1.4。

## 实现

- `src/backend/external_flow.h`：外部提交的 IO_Flow_Base 子类，复用原生 SQ、命令 ID、软件等待队列、CQ doorbell 和 PCIe_Link；稳定 token 独立于可复用 CID。检查 sector 范围和零长度，保留普通读写的原生计时。
- MQSim 的 `NVMe_read_sqe` 增加虚分派，外部 flow 为每个在途 CID 分配不同虚拟 DMA 地址。Root Complex 的可选观察回调只在原生 PCIe 投递后触发，提供地址与 payload 字节。按 DMA 地址关联数据、按 CQ 的 CID 关联请求；读 CQ 只有在全部数据到达后才发布值记录；未知、重复或不匹配完成报错。未附加回调时原生路径不变，未增加另一份传输计费。
- `src/backend/preload_window.h`：固定布局的页序预装载写入，逐次等待后端全部排空，涵盖 CQ doorbell、映射写回及后台事件。最后一次排空后记录 origin，测量只允许读取预装载范围。初始化不依赖未来读序列；不重置 MQSim 时钟或累计计数，测量使用时间偏移和计数差。
- MQSim 的只读研究快照导出实际映射（优先有效 CMT、否则 GMT）及 CMT LRU/状态/dirty 顺序，不调用会修改 LRU 的 Retrieve_ppa。初态包含 seed、预装载范围、数据缓存关闭、无 pending 事件/请求、映射及 CMT 状态。原生 `Get_current_cmt_occupancy_for_stream` 实际是 preconditioning 插入计数，输出明确命名为 `preconditioning_entries`；真实驻留集合由 CACHE 行记录。
- `configs/regression/ordinary.py` 和 `ndpsim.OrdinaryIO` 在真实 SST 上使用 M1.2 EventBridge；外部提交及窗口切换不会独立跑后端到未来。

## 验证入口与输入

运行 `python tools/archive/v0.1/verify_m1_3.py`，根 CMake 默认准备锁定 SST。具体命令、退出码、输入/依赖/源码哈希和日志见 [运行证据](../../evidence/m1.3/README.md)。

固定 native-small 几何、seed=321、512 B sector、4096 B page、SIMPLE/TURNED_OFF、无原生 preconditioning。先对 LBA [0,512) 发出 64 个完整页写入。测量矩阵：

| 场景 | CMT 字节 | 测量请求 |
| --- | ---: | --- |
| QD1 | 65536 | LBA 7，10 sectors，一次读取 |
| 多并发/同刻/排队 | 65536 | 同刻发出 32 读，LBA `7+(i%16)*16`，每读 10 sectors，超过 16 槽 SQ 的有效容量 |
| CMT miss | 128 | 相同 32 读，要求测量期 read CMT miss 增量大于零 |

每个读取从 page 的最后一个 sector 开始，跨三页；包含重复/重叠读取。逐请求比较 token、LBA、sectors、方向和整数 ns CQ 时间，以及初态映射/CMT/LRU；每组 SST 重跑一次并逐行一致。另检查预装载前测量读取、零长度提交被拒绝。CTest 包含原有回归。

原生 oracle 由 deps.lock.json 的原生 commit 独立 git archive 导出，直接编译原生所有后端源码；没有从修改的工作区构建。`tests/ordinary_native.cc` 在测试驱动中访问原生引擎私有事件树，按原生 Start_simulation 的初始化和内层事件循环执行，在队列排空后允许外部再次注入。源码不修改；其限制是与桥接共用外部请求/预装载驱动，并非独立实现的负载生成器。原生没有虚拟 SQE 分派和数据到达回调，仍使用原生 dummy DMA 地址；只比较完成行为，数据关联的提前可见防护由适配端检查。

## 限制

- 当前矩阵只覆盖 native-small、单 namespace/queue、单 SST rank/thread；未验证的数据缓存、几何、写测量负载不属于通过范围。预装载为功能布局写入，不是稳态 SSD 校准。
- 初态摘要覆盖该布局映射、CMT 和排空状态，不是整个设备 checkpoint；未序列化随机生成器及全盘 block 元数据，不支持恢复或同进程重复 Reset。
- 分页输入和真实 FTL/NAND 路径已运行，但本任务没有新增逐子事务观测差分；完整内部观测归 M1.4，正式本地路径和共享 PCIe 混发归 M3.2。不能将本矩阵推广为完整 AC-08 全路径通过。
- MQSim 仍不搬运真实向量 payload；此处关联的是传输范围和字节，真实逻辑内容与驻留由 M2.1 实现。外部读取必须由上层在合法 SST 提交阶段调用。
- ASan 检查不等于泄漏审计或 UBSan 通过；已有上游随机数溢出限制保留。参数 configured_unvalidated，不给出绝对性能或盘控加速结论。
- 验收时 MQSim 修改直接保留在 submodule 工作区，manifest 记录锁定基线、当时工作区 diff 和实际源码哈希。现已按用户授权提交为 `ba5a18dfdd8aebe796ef0edab3fb132dc3f1e494`，主仓 gitlink 同步指向该提交；未推送。
